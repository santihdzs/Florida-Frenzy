# Historias de Usuario – Florida Frenzy

## Historia de usuario #1 – Experiencia del juego
**Como usuario**  
quiero que el juego sea divertido y entretenido  
para poder disfrutar la experiencia de juego.

**Validación:**
- El jugador puede completar una partida
- El juego presenta desafíos interesantes

**Restricciones:**
- El juego debe ser fácil de comprender para nuevos jugadores

**Prioridad:** Alta  
**Estimación:** 10h  
**Tipo:** No-Funcional
